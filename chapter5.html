7.1 NAND2：先设计下拉网络

NAND2 只在 A=1 且 B=1 时输出 0。因此 PDN 中两只 NMOS 串联；PUN 是其对偶，两只 PMOS 并联。

ABPDNPUNY
00断两支导通1
01断A 支导通1
10断B 支导通1
11通断0
 
.subckt NAND2X1 A B Y VDD VSS
MPA  Y A VDD VDD pmos W=1u   L=0.15u
MPB  Y B VDD VDD pmos W=1u   L=0.15u
MNA  Y A X   VSS nmos W=0.5u L=0.15u
MNB  X B VSS VSS nmos W=0.5u L=0.15u
.ends NAND2X1

X 是两只串联 NMOS 的内部网络。上面尺寸仍只作语法示意；串联堆叠常需根据目标输入转换时间和输出负载重新调整尺寸。

7.2 NOR2：把串并联互换

NOR2 在 A=1 或 B=1 时输出 0，所以 PDN 中 NMOS 并联；PUN 中 PMOS 串联。

.subckt NOR2X1 A B Y VDD VSS
MPA  X A VDD VDD pmos W=1u   L=0.15u
MPB  Y B X   VDD pmos W=1u   L=0.15u
MNA  Y A VSS VSS nmos W=0.5u L=0.15u
MNB  Y B VSS VSS nmos W=0.5u L=0.15u
.ends NOR2X1
不要把 AND2 画成四只晶体管。四管静态 CMOS 网络直接得到 NAND2。普通静态 CMOS AND2 通常是 NAND2 后接反相器，共 6 只晶体管；OR2 同理通常由 NOR2+INV 构成。

7.3 源漏共享的条件与扩散区断开

若把晶体管排成一行，要让左管右端与右管左端共享一块源漏扩散区，这两个端子必须属于同一网络。这是共享所需的电路连接条件；是否符合器件与工艺要求，还要继续检查。以 NAND2 为例：

  • NMOS 串联可排成 Y-[A]-X-[B]-VSS，共享内部网络 X。
  • PMOS 并联可折返成 Y-[A]-VDD-[B]-Y，两管都连接 Y↔VDD。

这也说明“连续 Active 上所有位置都属于同一网络”不成立：每个 gate 下方是受控制的沟道，gate 两侧的扩散片段可以是不同网络。

“源漏共享”实际共享了什么

“源漏共享”是初学者常用说法，更准确的名称是源/漏扩散区共享：两只相邻、同类型 MOS 的相接端属于同一个电气网络，并且器件与工艺条件允许时，可以用同一块物理扩散区作为两只器件的公共端子。共享的是一个扩散片段，不是整只晶体管，也不是栅；共享区域不一定需要 Contact。

“相接端网络相同”只是必要的拓扑条件。真正合并前还要确认两只器件的阱/体偏置、注入层、Vt/电压类型、器件方向和目标 PDK 隔离规则兼容；即使都是 PMOS，不同电压域或不同器件选项也未必允许共享。

网表能帮助判断共享机会，是否已经共享要看版图。普通 SPICE 电路网表描述器件、网络连接及 W、L 等参数，但不提供足以确定器件相邻、Active 连续和扩散区断开的完整几何信息。即使附带部分坐标注释，也不能代替实际版图检查。

diffusion break：Active 在这里断开了

在本章的平面 MOS 版图语境中，diffusion break（扩散区断开）就是两只器件之间的 Active 不连续，分成两块有源区。版图上是有源区之间的间隔，实际工艺中对应隔离区域，不是硅片上留了一个空洞。

  • 共享扩散：相邻两只 MOS 共用中间的一块源漏扩散区；该区域有无 Contact 都不影响“共享”的判断。
  • 扩散断开但电气相连：两块分开的扩散区也可以各自通过 Contact 接到同一条 M1。这是金属互连，不是源漏共享。
  • Poly 跨过 Active：形成 MOS 的栅控制区域，不属于 diffusion break。栅下沟道是否导电取决于偏置，不能把晶体管关断等同于 Active 几何上断开。

所以，电路上连接同一个网络，不等于版图中一定画成一块连续扩散区。同一个电路可以有不同的版图实现。

从 SPICE 网表判断共享机会

常见 MOS 实例顺序是 Mname D G S B model。先忽略“左边一定是源、右边一定是漏”的想法，把 D 和 S 当作两个源漏端；如果两只同类型 MOS 能翻转到：

左管的右端网络 == 右管的左端网络

它们就满足了共享的网络条件；还需满足前述工艺条件。下一节先用较简单的 NOR2 解释如何寻找整行顺序。下面保留 OR2 的拓展例子，第一次阅读可以先跳过。

选读：从 OR2 网表找共享机会，再排成完整扩散序列

以下是一个 OR2（NOR2 后接反相器）中的片段：

M_i_2 ZN_neg A1 VSS    VSS NMOS_VTL
M_i_3 VSS    A2 ZN_neg VSS NMOS_VTL
M_i_4 net_0  A1 ZN_neg VDD PMOS_VTL
M_i_5 VDD    A2 net_0  VDD PMOS_VTL
器件对共同网络一种连续扩散排列
M_i_2、M_i_3两管都连接 ZN_neg↔VSSZN_neg-[A1]-VSS-[A2]-ZN_neg，中间共享 VSS
M_i_4、M_i_5net_0ZN_neg-[A1]-net_0-[A2]-VDD

加入输出反相器的 M_i_0 和 M_i_1 后，还可以得到完整的同类型连续排列：

NMOS：ZN-[ZN_neg]-VSS-[A1]-ZN_neg-[A2]-VSS
                     ↑共享 VSS       ↑共享 ZN_neg

PMOS：ZN-[ZN_neg]-VDD-[A2]-net_0-[A1]-ZN_neg
                     ↑共享 VDD       ↑共享 net_0

这两条序列各自满足相邻源漏网络相同，但栅顺序分别是 ZN_neg、A1、A2 与 ZN_neg、A2、A1，并未直接得到上下对齐的共同顺序。下一节会解释这两个目标的区别。

即使 NMOS 与 PMOS 都连接 ZN，它们也不能共享同一块扩散区：两者掺杂类型和井结构不同，必须各自形成扩散区，再用金属连接同名网络。NMOS 与 PMOS 的栅可以对齐或用 Poly/金属相连，但那也不叫源漏共享。

7.4 为什么找 Euler 路：从源漏共享到晶体管排序

先记住目的：找 Euler 路，是为了给晶体管安排顺序和朝向，让相邻器件尽量共享源漏扩散区。它不是寻找实际电流路径，也不是寻找最短布线路径。

第一步：先问版图设计者想解决什么

上一节回答了“两只管能不能共享”。现在问题扩大了：给你一组同类型晶体管，怎样把它们排成一行，让相邻端子都能接得上？先假设器件与工艺允许共享，暂时只考虑网络连接。我们希望：

  1. 不漏：每只晶体管都要排进去，否则电路缺了器件。
  2. 不多：每只晶体管只安排一次，不能为了接得上就凭空多画一只。
  3. 接得上：前一只的右端与后一只的左端属于同一网络，中间才有机会共用一块扩散区。

如果找到这样的顺序，就得到一条不需要在相邻器件之间插入扩散断点的拓扑候选。这通常有利于减少为分开的扩散端预留的空间和部分接触、互连开销，但实际收益仍要检查工艺规则和完成后的版图。

NAND2、NOR2 只有几只管，人很容易看出顺序。器件更多时，顺序和朝向的选择会增多，程序就需要一种系统的寻找方法。Euler 路正好把上面三个要求表达出来。

第二步：把排序问题翻译成“点和边”

PMOS 和 NMOS 分别建立自己的图。这里的图不是直接照抄原理图符号，而是只提取源漏连接关系：

电路或布局中的东西图论中的表示为什么这样表示
源漏端连接的网络，如 VDD、VSS、Y、X顶点，也就是“点”相接端网络相同，就是两条边能在同一个点衔接
一只 MOS 的两个源漏端一条连接两个点的边经过这条边，就表示在排列中使用这只 MOS 一次
MOS 的栅信号，如 A、B边上的标签记录这只管应由哪个信号控制，供上下行对齐时使用

两只并联 MOS 会连接同一对点，但它们仍是两条不同的边，这叫多重图。同一个栅信号也可以控制多只 MOS，因此不能只靠栅标签判断是不是同一条边，还要保留器件身份。

在允许交换源漏朝向的简化排列问题里，用无向图表示：沿边从哪端走到哪端，对应把该器件哪端朝左、哪端朝右。实际器件如果不允许交换源漏，还必须额外保留方向约束。

现在，布局的三个要求就变成了：连续经过全部边，而且每条边恰好经过一次。这种路线叫 Euler trail（欧拉迹），本教程也沿用常见说法“Euler 路”或“Euler 路径”。它并不是额外强加给电路的规则，而是对连续扩散排列问题的数学表达。

第三步：用已经看懂的 NOR2，亲手走一遍

沿用 7.2 节网表中的名字：输入 A、B，输出 Y，PMOS 内部节点 X。若你手头单元的引脚叫 A1/A2、输出叫 ZN，先按实际连接对应名字即可；本节不依赖某一种命名方式。

器件栅标签连接的两个源漏网络电路关系
MPAAVDD ↔ X通过 X 串联
MPBBX ↔ Y
MNAAVSS ↔ Y两条支路并联
MNBBVSS ↔ Y

PMOS 可以从 VDD 出发：经过 MPA 到 X，再经过 MPB 到 Y。两条边都只使用一次，而且在 X 接得上，所以得到：

VDD --[MPA，栅 A]-- X --[MPB，栅 B]-- Y

翻译回版图：左管右端是 X，右管左端也是 X，因此中间可以共享 X 扩散区。这个内部节点不一定需要 Contact，直接共用扩散区就能建立两管之间的连接。

NMOS 可以从 VSS 出发：经过 MNA 到 Y，再经过另一条边 MNB 回到 VSS：

VSS --[MNA，栅 A]-- Y --[MNB，栅 B]-- VSS

翻译回版图：两只 NMOS 可以共享中间的 Y 扩散区。VSS 出现两次并没有违反要求：允许重复经过同一个点，不允许重复使用同一条边。这里使用的是 MNA、MNB 两只不同器件，不是同一只管走了两遍。

画成一行，不代表电路变成串联。两只 NMOS 仍然各自连接 Y 与 VSS，所以仍是并联。版图左右两端的 VSS 还需要接到同一个电源网络；Euler 排列并没有替你完成这些金属互连，也不要求把 Active 弯成一个环。

这里的“走一遍”只是在整理连接与排列，不是给输入赋值后追踪实际电流。找顺序时不会先要求这些晶体管同时导通；判断 NOR 的功能仍然要按照输入电平分析上下拉网络。

第四步：为什么还希望上下两行有“共同顺序”

把刚才两行只保留网络和栅标签，按未来版图从左到右的方向写出来：

PMOS: VDD --[A]-- X --[B]-- Y
NMOS: VSS --[A]-- Y --[B]-- VSS

方括号表示栅跨过有源区的位置，整段文字只是排列示意，不表示实际尺寸。两行的栅标签都是 A、B：上方 A 与下方 A 可以对齐，上方 B 与下方 B 也可以对齐，便于在规则允许时用同一列 Poly 连接。

  • 横向目标：同一行相邻器件尽量共享扩散区。
  • 纵向目标：上下两行相同信号的栅尽量对齐，减少栅信号绕线。

因此“共同 Euler 顺序”是指 PMOS 图和 NMOS 图分别选出的路线，具有相同的栅标签顺序；不是说它们经过相同的源漏网络，更不是让 PMOS 与 NMOS 共享扩散区。各自存在 Euler 路，并不保证两行一定找得到共同顺序。

选读：什么时候存在 Euler 路？先理解用途，再看这个判据

顶点的度是连接到这个点的边的数量；平行边分别计数，自环计两次。对至少有一条边的无向图，忽略孤立顶点后，图必须连通，而且奇数度顶点只能有 0 个或 2 个。

  • 2 个奇数度顶点：路线从一个奇点开始，在另一个奇点结束。上面 PMOS 图的 VDD、Y 度为 1，X 度为 2，符合这个情况。
  • 0 个奇数度顶点：可以回到起点，叫 Euler circuit（欧拉回路）。上面 NMOS 图中，VSS、Y 都连接两条边，度都为 2。

这只是源漏连接图的判据，不保证工艺规则、上下栅对齐或布线全部可满足。本章先会解释“为什么找”，更完整的图论与算法练习见图论基础和Euler 与最短路实验。

把这条因果链说出来就抓住了重点：希望相邻器件共享扩散区 → 需要合适的器件顺序和朝向 → 每只管恰好一次、相邻端子网络一致 → 转成图后就是寻找 Euler 路。

7.5 找不到共同 Euler 路怎么办

没有合适的共同 Euler 顺序，并不等于电路不能画。它是一种布局优化方法，不是电路正确的必要条件。不能为了保持一条 Active 而改变网络。可选策略包括：

  1. 在保持每只器件连接不变的前提下，换起点、改变器件排列或枚举另一条 Euler 路；不是直接把 A、B 的接线换掉；
  2. 在器件与工艺允许时，翻转某只 MOS 的源漏朝向；
  3. 在一行中引入 diffusion break；
  4. 按原电路要求把宽晶体管折成多个并联 finger，保留相应尺寸与端子关系，再对这些物理器件重新建图和排列；不能无条件复制一只原尺寸晶体管来凑路线；
  5. 接受多一段局部互连，以换取更好的引脚可接入性、规则裕量和更低拥塞。

最少 diffusion break 不是唯一目标。断开扩散后用 Contact 和金属连接相同网络，是正常的版图实现方法。一个更窄却无法布线或 pin 无法从上层访问的单元并不是更好的单元；Euler 路也不保证面积、寄生、功耗或时序全局最优。

7.6 从 NAND/NOR 走向复杂门

例如 AOI21：

Y = NOT(A·B + C)

PDN：A 与 B 串联，这一支再与 C 并联
PUN：对偶网络——A 与 B 并联，这一组再与 C 串联

先在逻辑层构造 PDN，再做对偶得到 PUN；随后给每个内部网络命名，转换为图，寻找共同栅顺序。这个过程可推广到 AOI/OAI 等复杂组合门。

7.7 下一步：从电源通路走向信号通路

本章 NAND/NOR 的输入接在栅上，控制输出与 VDD/VSS 之间的通路。下一章换一个问题：如果想把已经存在的数据 X，按控制条件传到 Y，该怎样连接 MOS？这就是传输门要解决的任务。

传输门基础现已独立成章：从单管传输到 MUX 与锁存器。从 NMOS 为什么传弱 1、PMOS 为什么传弱 0 开始，再逐项读四端网表和概念版图，搭出 MUX 与反馈锁存器，并运行四组波形实验。本节保留原有锚点，方便旧书签继续找到入口。

暂时记住一个区别即可：静态 NAND/NOR 的数据通常进入 MOS 栅；TG 的数据经过源漏端，栅上接的是使能控制。源漏共享的判断方法仍可使用，但不能把 N/P 器件电气并联误认为它们共享了一块扩散。

纸上实验 A：为 NOR2 排扩散
  1. 根据本章 NOR2 网表，列出 PMOS 图和 NMOS 图的顶点、边。
  2. 写出一个连续 PMOS 扩散序列和一个连续 NMOS 扩散序列。
  3. 圈出每行的共享扩散网络，再检查两行的栅标签能否对齐。
  4. NMOS 序列中同一个网络出现两次，是否违反“每条边只经过一次”？这些不同位置的同名扩散区还需要怎样连接？
  5. 用自己的话解释：为什么我们找的是晶体管排列路线，而不是实际电流路径？
一种答案与逐项检查

PMOS 图有 VDD、X、Y 三个顶点，MPA、MPB 两条边；NMOS 图有 VSS、Y 两个顶点，MNA、MNB 两条平行边。可取 VDD-[A]-X-[B]-Y 与 VSS-[A]-Y-[B]-VSS。共享区分别对应 X、Y，两行栅顺序均为 A、B。

NMOS 的 VSS 出现两次，是同一个顶点被再次访问；MNA、MNB 各使用一次，没有重复使用边。两端 VSS 扩散区仍需接到同一个电源网络，例如都通过 Contact 接到 VSS 金属轨。

找排列时不先给 A、B 赋值，也不要求相关晶体管同时导通；它只规定器件顺序、朝向和公共端子。实际电流路径取决于偏置和输入状态，不能把两者混为一谈。

还可以反向阅读两条序列，得到 Y-[B]-X-[A]-VDD 与 VSS-[B]-Y-[A]-VSS，共同栅顺序变成 B、A。这里改变的是排列方向，器件原有的栅和源漏网络连接并没有改变。

本章检查点
  1. 两个 PMOS 共享一块扩散，是否一定串联？为什么？
  2. 为什么网表只能判断共享机会，不能证明版图已经共享？
  3. Active 断开后，两个端子还能属于同一网络吗？Poly 跨过 Active 是不是 diffusion break？
  4. 下一章的 TG 与本章 NAND/NOR，数据进入的 MOS 端子有什么不同？
  5. 不用背公式，先说出找 Euler 顺序想解决哪三个排列要求，再说明顶点、边和边标签分别对应什么。
  6. 为什么 Euler 路允许 VSS 出现两次，却不允许把同一只 MOS 无条件使用两次？
  7. 共同 Euler 顺序能优化什么，又不能保证什么？
参考答案
  1. 不一定，串并联由两端网络拓扑决定，不能根据版图排成一行就认定串联。
  2. 普通网表有器件、连接及 W/L 等参数，但没有确定器件相邻和 Active 连续性的完整版图几何。
  3. 可以，分开的扩散区可通过 Contact 与金属相连。Poly 跨过 Active 形成栅控制区域，不是扩散区几何断开。
  4. NAND/NOR 的数据输入通常接栅，控制电源到输出的通路；TG 的数据进入源漏，栅接使能控制，具体原因和应用在下一章展开。
  5. 每只管都排进去、每只只用一次、相邻管的相接端网络一致。顶点是源漏网络，边是 MOS，边标签是栅网络。
  6. 网络顶点可以重复访问；器件边恰好一次，防止漏掉或额外使用器件。若主动做了合法折指，必须先按新的物理器件集合重新建图。
  7. 共同顺序有利于扩散连续和上下栅对齐，但不能保证 DRC、最小面积、内部布线、引脚可接入性、寄生或时序最优。找不到共同顺序仍可以分段布局并用金属连接。
阅读依据：静态 CMOS 基础参考 Baker 的 CMOS: Circuit Design, Layout, and Simulation；Euler 版图直觉参考 Uehara 与 vanCleemput 的经典 CMOS functional array 方法，以及《CMOS版图设计基础》的 Euler/stick diagram 示例。晶体管布局章节将从 LibreCell 布局器源码角度进一步说明 Euler 方法与适用边界。
