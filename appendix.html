A.1 版图与器件术语

术语本教程中的精确定义
Active / OD允许形成器件有源区域的层/层组；结合 well/implant/gate 才确定器件和 S/D。
Diffusion历史上常泛指有源/掺杂源漏区域；本地 LibreCell 直接区分 ndiffusion/pdiffusion 内部层。
Implant / Select选择掺杂或器件类型的层；不是导线。
Well / BodyNMOS/PMOS 所在体区及 MOS 第四端 B；需通过 tap 接到规定网络。
Poly / Gate穿过 Active 的有效交叠形成受控沟道；离开 Active 的 Poly 可作为局部连接。
ContactActive/Poly 到局部金属的垂直连接；不会切断 Active。
Via / 通孔相邻金属层间的垂直连接；两个金属层只重叠而无通孔通常不导通。
W / LL 沿源漏电流方向量 gate 的短尺寸；W 是与电流方向垂直的沟道宽度。
Finger把一只宽 MOS 折成多条并联 gate；总有效 W、寄生和端部效应需按 PDK 计算。
Tap把 well/substrate 接到 VDD/VSS 或 body-bias 网络的结构/专用单元。
Abutment / 相邻拼接标准单元紧邻排列后的边界拼接；需在所有合法朝向下验证。
Pin access / 引脚可接入性芯片级布线器能在规则允许的条件下放置通孔并接入引脚；不等于引脚图形存在。

A.2 库与验证术语

术语含义
PDK工艺设计套件：规则、层、器件、模型、deck、工具配置和参考资料的集合。
DRM设计规则手册，用于理解 rule intent/condition；不等同于签核 deck。
DBUdatabase unit，版图整数坐标的物理长度。
GDS/OASIS保存制造相关层几何和层次的版图交换格式。
LEF给 P&R 的物理抽象：boundary/size、site、pin port、OBS 等。
CDL/SPICE晶体管/器件网表，包含端子、模型和参数。
Liberty逻辑、时序约束、延迟、输出转换时间、功耗和 PVT 模型。
DRC版图几何对设计规则的检查。
ERC对提取网络的电气规则检查，如 well、电压、悬空网络。
LVS版图提取网表与参考网表的器件/网络/参数比较。
PEX从版图提取互连/器件寄生 R/C 等，供版图后仿真。
PVTprocess、voltage、temperature 条件组合。
Slew / Load输入转换快慢与输出负载；Liberty 表常以二者作为索引。
Timing arc / 时序弧某关联引脚的变化与目标引脚延迟、转换时间或约束之间的关系。
Layout / 版图制造相关几何及其电路实现；本教程不用“布局”指代 layout。
Placement / 布局决定单元或晶体管的位置、顺序与朝向；placer 译为布局器。
Routing / 布线为网络选择合法路径并形成走线；router 译为布线器，routing graph 译为布线图。
P&R / 布局布线placement and routing 的合称；芯片级 P&R 使用标准单元，而 LibreCell 主要生成单个标准单元的版图。
Floorplanning / 布图规划确定芯片/模块的区域、宏单元、I/O、电源和通道等总体物理结构，早于详细布局。
Characterization / 特征化在 PVT、输入转换时间和输出负载等条件下建立单元时序、功耗与约束模型；“表征”是可见译法，但正文统一使用“特征化”。
Extraction / 提取从版图识别器件、网络或寄生参数；正文统一使用“提取”，避免与普通文字的“抽取”混用。
Signoff / 签核使用项目批准的规则、工具和条件完成最终验收；不等于任意检查工具显示通过。
Filler填补空站点并保持 well/implant/power 等连续的物理单元。
Endcap处理 row/井/implant 边缘规则的物理单元。
Tap cell在 tapless 架构中周期性提供 well/substrate 连接的单元。

A.3 算法术语

术语用途
MultiGraph允许同一对顶点间多条边，适合表示并联 MOS。
Connected component内部任意两点可达的最大子图；本地 hierarchical partition 的核心。
Euler 迹/回路每条边恰好使用一次；用于构造连续扩散区的晶体管顺序。
Dijkstra在非负权图上求最短路径；本地用于逐步连接多端 net。
Steiner 树连接指定端点并允许额外分叉点；精确问题一般为 NP-hard。
PathFinder通过当前/历史成本反复拆线重布，协商多个网络的拥塞。
HPWL/包围盒估计用网络端点包围盒的半周长估计线长；计算便宜，但不等于实际布线线长。
SMT可满足性模理论，把整数、布尔和优化约束交给 solver。

A.6 排错决策树

lclayout 还未进入 main？
├─ import/module error → 激活正确 venv，核对 Python/lock/z3/klayout
└─ 已开始读取输入
   ├─ 找不到 subckt → cell 名、netlist path、大小写
   ├─ 找不到 power/ground → 端口命名与唯一性
   ├─ MOS 类型/尺寸异常 → model mapping、W/L 单位、DBU、sizing clamp
   └─ 已开始布局
      ├─ 布局搜索爆炸/很慢 → 布局器、Euler 候选、层次分区
      └─ 已构建布线图
         ├─ 无端点 → 网格节距/偏移、端子、通孔包围和间距
         ├─ 图不连通 → routing_layers、通孔连接图、被删除的非法边
         ├─ Failed to route → 资源/冲突/布局，再比较布线器/成本
         └─ 已画完 layout
            ├─ 内部 LVS fail → pin/device/open/short；外部 LVS 进一步确认
            ├─ 外部 DRC fail → 按 rule ID 聚类并追到生成字段/模块
            ├─ 外部 LVS fail → body/model/layer derivation/端口/参数
            ├─ LEF/P&R 失败 → 尺寸/站点/引脚/用途/OBS/引脚可接入性
            └─ 特征化异常 → PVT/模型/测试平台/PEX/单位/时序弧

A.7 最常见的错误认知

错误说法正确说法
绿色一定是 Active颜色是显示配置，必须查 layer map。
Contact 可以切断扩散Contact 建立垂直连接，不切断 Active。
并联 MOS 必须分开画只要网络顺序允许，也可折返共享 diffusion。
数字 MOS 只经过截止和线性区切换时会经过不同工作区，包括饱和区。
反相器任何时刻只有一只管导通稳态近似如此；切换期间可能同时部分导通。
四管可以实现普通静态 CMOS AND2四管得到 NAND2；AND2 通常 NAND2+INV，共 6T。
内部 LVS pass 就是 foundry LVS pass本地内部 LVS 忽略 body 且层能力有限。
生成 GDS/LEF 就完成了库还缺外部签核、PEX、Liberty/Verilog/CDL、一致性和 P&R QA。
PDF 描述的算法就是 LibreCellPDF 是独立的 2003 年无网格/河流式布线工具；当前源码使用网格布线图和 PathFinder。
