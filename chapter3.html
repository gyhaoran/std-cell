第 3 章　版图如何变成晶体管

掌握一套不依赖配色的逐层读图法

本章目标
  • 知道有源区、多晶硅、注入层、井、接触孔、通孔和金属分别表达什么。
  • 看到 Active × Poly 就能定位沟道，并数出晶体管。
  • 沿扩散、接触孔和金属追踪网络，写出每只 MOS 的 G/D/S/B。

3.1 版图是俯视的几何数据库

GDS/OASIS 保存的是层号、datatype、polygon/path/text 等几何对象。版图工具把不同层叠加显示，好像多张透明胶片。颜色和填充图案只是显示配置，不是 GDS 的电气含义；换一个 PDK 或 layer-properties 文件，同一层可能完全变色。

版图也不是晶圆剖面的照片。俯视图中的矩形往往表达“在这个平面范围执行某道工艺或形成某种材料”，制造后会变成有厚度、掺杂浓度和三维形貌的结构。

第一条读图纪律：先查看目标 PDK 的 layer map 和显示文件，再解释颜色。不要说“绿色永远是有源区、红色永远是 Poly”。教程配色只为保持教学图一致。

3.2 新手必须认识的层

层或层组几何作用电气含义/注意事项
Well定义 N-Well、P-Well 等体区决定器件体区和隔离；需通过 tap 连接 body 网络。
Active / OD / diffusion允许形成器件有源区域单独出现不一定就是某种 S/D；通常还要结合 well 与 implant。
N/P implant 或 select选择掺杂类型Active+N implant 常形成 N+，Active+P implant 常形成 P+；实际派生规则以 PDK 为准。
Poly / gate形成栅或局部连接穿过 Active 的部分控制沟道；离开 Active 的 poly 不会凭空形成 MOS。
Contact / cut在 Active/Poly 与 M1 之间建立垂直连接必须同时满足 cut 大小、间距及上下层 enclosure。
Metal1, Metal2…同层内的导电互连相交不等于跨层连接；跨层通常需要相应通孔（via）。
Via1, Via2…连接相邻金属层例如 Via1 通常连接 M1↔M2；名称与堆栈由 PDK 定义。
Pin / label / boundary给工具标记端口和单元边界有些是非制造层；文字重叠金属也不一定自动建立电气连接。

3.3 识别一只 MOS：寻找 Active × Poly

  1. 找 Active。先只显示 Active/OD，观察连续条带和岛状区域。
  2. 叠加 Poly。每一处 gate-poly 穿过 Active 的有效交叠，通常对应一只 MOS 或一个 finger。
  3. 判断类型。结合 well、implant/select 和 PDK 的器件提取规则，确定 NMOS/PMOS。
  4. 标出两侧扩散。Poly 两侧分别是这只器件的两个 S/D 端；不要先入为主认定左边是 S。
  5. 找到栅网络。沿 Poly 或 poly contact→M1 追到输入 pin。
  6. 找到 body。沿 well/substrate 和 tap 追到电源，或确认该库采用外置 tap-cell 架构。

一条 Active 被两条 Poly 依次穿过时，可以按下面的序列读：

扩散网络 N0 ─[栅 A]─ 扩散网络 N1 ─[栅 B]─ 扩散网络 N2

它表示两只晶体管共享中间扩散 N1。
若 N0=Y、N1=X、N2=VSS，则电气路径是 Y → MOS(A) → X → MOS(B) → VSS。

3.4 Contact 不会“切断”Active

Contact 的作用是建立垂直连接：把下方扩散或 Poly 接到上方金属。它不会把一条 Active 切成两个互相绝缘的区域。要让相邻晶体管无缝共享扩散，连接条件必须本来就满足：

左边晶体管的右侧网络 == 右边晶体管的左侧网络

如果两侧应属于不同网络，常见做法是分开 Active、调整晶体管顺序，或依照 PDK 使用专门的 diffusion break 结构；绝不是“放一个 contact 把它切开”。

另外两个常见误判：两个不同金属层的矩形上下重叠但没有通孔，电气上不连接；一个引脚标签压在金属附近，也必须确认引脚用途层和端口图形的定义，不能仅凭文字位置判定连接。

3.5 固定的六步追线法

面对任何陌生标准单元，按以下顺序做，不要一开始就试图猜逻辑门名称。

  1. 确认图层语义：从 PDK 层映射得到井、有源区、注入层、多晶硅、切割层、金属、通孔和引脚层。
  2. 定位电源和体区：找 VDD/VSS rail、N-Well/P-Well 及 tap。
  3. 数晶体管：只数有效的 Active×gate 交叠，并记录 NMOS/PMOS。
  4. 给扩散片段编号：每条 gate 的两侧先写临时名 N0、N1，再沿 contact/metal 合并同一网络。
  5. 给栅编号：沿 poly/contact/metal 找到 A、B 等 pin；同一条输入可能驱动一只 PMOS 和一只 NMOS。
  6. 写网表并验逻辑：逐只写 M D G S B model，再检查 PUN/PDN 是否互补、真值表是否成立。
版图观察可得出的电路结论仍不能武断得出的结论
一条 Poly 穿过一条 Active存在一个受该栅控制的沟道器件类型、W/L 和端子网络仍需更多层信息
两只 MOS 共用一片栅间扩散它们有一个共同 S/D 网络仅凭外观不能说串联或并联，需看另两端网络
两个 M1 图形接触/重叠通常属于同一个几何连通体仍需排除 purpose、slot/cut 等 PDK 特例
M1 与 M2 重叠空间位置重叠没有 Via1 就不能认为电气连接
扩散位于 N-Well 内它可能是 PMOS 区域的一部分仍需 implant/select 和器件提取规则确认

3.6 串联、并联在版图里怎么看

串联看网络拓扑：两只晶体管仅共享一个中间网络 X，外端分别接 Y 与 VSS。并联则要求两只晶体管的两端分别属于同一对网络，例如都连接 VDD↔Y。并联器件也可以用一条折返的连续 Active 实现为 Y-[A]-VDD-[B]-Y，因此“并联晶体管必须分开画”也是错误的。

3.7 第一次纸上读图实验

实验：从几何序列还原网络

给定 NMOS 行 Y-[A]-X-[B]-VSS，PMOS 行 VDD-[A]-Y-[B]-VDD：

  1. 列出四只 MOS 的两个扩散端与栅。
  2. 判断 NMOS 行与 PMOS 行分别是串联还是并联。
  3. 写出输出逻辑。
参考答案

NMOS：A 管连接 Y↔X，B 管连接 X↔VSS，为串联；PMOS：A、B 管都连接 VDD↔Y，为并联。PDN 仅在 A=B=1 时连通，因此 Y=NOT(A AND B)，是 NAND2。
