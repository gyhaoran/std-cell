从零读懂并生成 CMOS 标准单元

版图识读、图算法、LibreCell 源码、新工艺迁移与库级验证

这是一份可以从头自学、也可以按基础跳读的标准单元教材。从电压、电容、逻辑符号和电路图开始，逐层读懂平面 CMOS 版图，再进入图算法、LibreCell 源码、工艺适配和时序库表征。每个学习单元都给出前置知识、可跳过的自测条件和可检查的学习产物。

先知道教程的边界

本教程对齐本机 LibreCell 仓库提交 f708e3a。该仓库 README 明确说明项目仍处于早期阶段，不宜把“程序生成了 GDS”误认为“已经达到可投片的工业标准”。教程中的 LibreCell 内部 LVS、LEF 输出和后处理都会如实说明能力边界，并另外安排外部签核闭环。

学完后应当能做什么

读懂版图

从图层交叠识别 NMOS/PMOS，追踪栅、源漏、接触孔、通孔和金属网络，并把它还原为晶体管级电路。

读懂算法

会把晶体管网络和布线资源表示成图，理解 Euler 路、连通分量、最短路、Steiner 树与拥塞迭代。

修改 LibreCell

知道技术文件字段在哪里被消费、流程经过哪些模块，以及何时只改配置、何时必须改代码并增加测试。

迁移新工艺

建立 PDK 能力矩阵，处理层映射、单位、器件模型、井与衬底连接、规则、输出视图及完整回归。

建议学习方式

  1. 从零自学按下面的 32 章顺序。章首自测能独立完成时，可跳到下一章；遇到术语障碍及时回到电学基础或工具上手。不要求所有人用相同速度学习。
  2. 每章都做检查点。答案折叠在页面中；先自己画、自己追线，再展开核对。
  3. 算法先在纸上走一遍。图的顶点、边、代价和容量都能说清楚后，再读 Python 实现。
  4. 生成结果必须外部验证。新工艺迁移以 foundry/PDK 的 DRC、LVS、PEX deck 为准，而不是以教程中的示意规则为准。
