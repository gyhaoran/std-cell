## 本次原则

检查的“类似问题”不只是篇幅短，而是新概念出现时，缺少必要背景、推导中间步骤、可跟着做的例子，或把示意、真实实现与验证证据混为一谈。本次直接修改正文，没有只留下建议清单。

- 前 7 章文件逐一比较修订前后的 SHA256，完全未变；维持 32 章与附录的次序。第 8 章已有完整传输门基础单元，继续沿用。
- 后续章首改为真实知识依赖。锁存器不再要求先学加法器，图论不再要求先懂全部物理单元，SPICE 入门不再以完成迁移项目为前提。
- 保留原页面和锚点；只在个别章内调整先后顺序，例如先解释二进制进位，再读加法器目录；先推导主从相位，再读 DFF/扫描/门控族。
- 所有新增工艺/延迟数字明确区分教学假设与本地真实资料；实际执行与未执行的验证分开说明。
