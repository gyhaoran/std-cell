第 13 章　技术文件逐字段拆解

以 examples/dummy_tech.py 为真实接口，不发明不存在的配置类

本章目标
  • 理解技术文件是被执行的 Python module，不是通用 PDK schema。
  • 掌握当前版本真正读取的全部字段及单位。
  • 能判断新工艺需求是输出映射、参数调整，还是内部层/器件/布线代码扩展。

13.1 技术文件如何被加载

tech_util.load_tech_file 使用 SourceFileLoader 执行传入的 Python 文件，然后其他模块直接访问 tech.db_unit、tech.min_spacing 等 module attributes。

安全与接口含义：--tech 文件具有执行任意 Python 的能力，只加载可信文件。当前代码没有 schema validator；字段拼错往往到流程深处才表现为 AttributeError 或错误几何。迁移项目应自行增加静态校验与单元测试。

13.2 内部层不是 PDK 层号

lclayout/layout/layers.py 固定定义了一套内部语义层：

ndiffusion, pdiffusion, nwell, pwell, poly
ndiff_contact, pdiff_contact, poly_contact
metal1, via1, metal2
metal1/metal2 label 与 pin，abutment_box

内部通孔连通关系也固定为扩散区/多晶硅↔M1 和 M1↔M2。技术文件中的 output_map 只是在输出阶段把这些内部层复制到目标 GDS (layer, datatype)，并没有把内部拓扑变成任意 PDK 层栈。

my_metal1 = (6, 0)
my_metal1_pin = (6, 2)

output_map = {
    l_metal1: my_metal1,
    l_metal1_pin: my_metal1_pin,
    l_nwell: [(2, 0), (2, 1)],  # 一个内部层可复制到多个输出层
}

如果目标工艺需要局部互连层（LI）、特殊栅接触栈、多种切割层、M3+、不同阈值注入层或布尔派生层，单靠 output_map 通常不够；要扩展内部层、通孔连接图、晶体管绘制、布线、LVS 和输出模块。

13.3 单位链必须完整推导

# 技术文件
db_unit = 1e-9  # 一内部整数单位 = 1 nm = 1e-9 m

# 所有 unit_cell_width、spacing、via_size 等都用内部整数单位
unit_cell_width = 400  # 400 nm，仅对这个 dummy tech 成立

输入 SPICE 的 W 经 KLayout netlist parser 读取后被转换到米，再除以 db_unit 形成内部 channel width，之后乘 transistor_channel_width_sizing 并夹到 NMOS/PMOS 最小 gate width。GDS writer 又把米/DBU 换为 KLayout 要求的 µm/DBU；LEF writer按自己的 db_unit 计算缩放。

迁移检查：选 INV 这样可手算的单元，从 SPICE W/L 一路打印到内部整数、GDS ruler 和 LEF SIZE/PIN 坐标。四者任一不一致就停止，不要靠“整体缩放 GDS”补救。

13.4 输出模块（writer）

output_writers = [
    MagWriter(tech_name="scmos", scale_factor=0.1, output_map={...}),
    LefWriter(db_unit=1e-6, output_map=output_map, site="CORE"),
    GdsWriter(db_unit=db_unit, output_map=output_map),
]

输出模块列表就是实际输出能力。删除一个 writer 就不会生成对应文件；添加新格式应实现 Writer 接口。Magic 的层名/缩放与 GDS 映射是两个不同配置，不能假定自动同步。

13.5 布线资源和层用途

字段真实含义典型风险
routing_layers内部层→h/v/hv/空串漏层或方向错误会让图断开；空串层可接触但无同层轨道
pin_layer信号 pin 的内部层必须存在对应 _pin/_label 内部层与 output map
power_layerVDD/VSS rail 所在内部层需与 P&R 电源连接和 LEF 约定一致
connectable_layers后处理填 notch 时允许跨 shape 合并的层错误加入金属会把不同 net 短路；dummy 只放 nwell

13.6 单元架构和器件几何字段

字段控制对象
unit_cell_width最小横向单元步长，也用于栅槽位节距；最终宽度是 (placement_width+1)×unit_cell_width
unit_cell_height固定 cell height 和上下电源轨 y 位置
gate_lengthPoly gate path 的线宽，也就是生成几何的沟道 L
gate_extensionPoly 超出 active 上下边界的长度
transistor_offset_y有源区到上下单元边界的纵向偏移；代码会检查与有源区/多晶硅间距的关系
minimum_gate_width_nfet/pfet输入 W 太小时的下限
transistor_channel_width_sizing对所有输入 W 的全局缩放因子
power_rail_width上下电源 path 宽度
minimum_pin_widthpin 相关最小尺寸参数

这些参数并非互相独立。例如 transistor_offset_y 必须同时容纳有源区间距与 gate_extension + poly spacing/2；栅中心还必须落在 x 方向布线网格上。

13.7 网格字段

routing_grid_pitch_x = ...
routing_grid_pitch_y = ...
grid_offset_x = ...
grid_offset_y = ...

网格节距（pitch）决定相邻候选节点的中心距，偏移（offset）决定第一列/行的位置。更密的网格提供更多候选但图更大，且不能自动使违规路径合法；更疏的网格可能让晶体管端子或引脚没有接入节点。注意 pitch/节距不同于图形边到边的 spacing/间距。每次改动都要运行布线图可视化和端点数量回归。

13.8 几何规则字段

字段结构消费位置
min_spacing{(layer1,layer2): integer}间距关系图、器件边界、非法布线边和冲突节点
minimum_width{layer: integer}基础几何/清理相关约束
minimum_enclosure{(outer,inner): integer或tuple}有源区/井、通孔/接触孔生成和端子接入
minimum_notch{layer: integer}布线后填补凹槽
min_area{layer: integer area}SMT-based minimum-area repair
wire_width{routing_layer: integer}走线绘制与间距裕量
wire_width_horizontal水平线宽覆盖值绘制水平边
via_size{cut_layer: side_length}接触孔/通孔几何和接入裕量

min_area 存面积，其他大多存长度；这是最常见的量纲错误之一。真实 PDK 的条件 spacing、密度、antenna、EOL 等并没有等价字段。

13.9 布线成本字段

字段作用
weights_horizontal/vertical每个内部层每 DBU 的横/纵边基础权重
via_weights跨层边成本；键是两个可连接层，不是 cut layer 名
orientation_change_penaltyHVGraphRouter 中水平/垂直方向切换的成本
multi_via指定层对的多通孔数量；本地检查要求层对键按字符串顺序排列

成本只影响合法候选之间的偏好，不替代几何规则。先确保图正确，再调成本。

13.10 适配能力矩阵

新工艺需求仅技术文件？说明
相同内部层栈，不同 GDS 层号通常可以修改 output_map 并用 layer audit 验证
尺寸、节距、基本宽度/间距/包围量改变部分可以字段可表达，但仍需完整外部 DRC
foundry 模型名不以 n 开头不可以需修改 net_util.get_channel_type 接口并测试
新增 LI/M3、多种通孔/接触孔不可以扩展内部层、通孔连接图、布线、输出模块和 LVS
implant、Vt marker、复杂派生层通常不可以output copy 不能表达任意布尔/条件生成
复杂 EOL/coloring/密度/antenna不可以完整表达需生成约束、后处理及外部 deck 闭环
body/tap 签核不可以靠内部 LVS需明确 cell 架构并接 foundry LVS/ERC
字段追踪实验

任选 via_size[l_via1]，用 rg 找出它在布线图、端子提取和走线绘制中的全部使用位置。修改字段前先写下每个位置期望的单位和层语义。

本章检查点
  1. 为什么把内部 metal2 映射成 PDK 的 M3 不等于支持了 M1–M3 完整栈？
  2. min_area 与 minimum_width 的量纲有何不同？
  3. 为什么技术参数改动必须同时检查布线图和外部 DRC？
参考答案

内部通孔连接图和接触结构仍只有固定层对，简单改名不会创建缺失层。min_area 是面积，minimum_width 是长度。布线图检查验证拓扑和接入资源，外部 DRC 覆盖生成器未表达的真实制造规则。
